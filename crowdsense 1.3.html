🧠 About CrowdSense

An intelligent crowd monitoring and route recommendation system designed to improve safety during large public gatherings in Bengaluru and beyond.

📡

Real-Time Monitoring

Crowd data is collected continuously from CCTV cameras, GPS signals, WiFi/Bluetooth device detection, and entry gate sensors to build a live picture of crowd density.

🧮

Density Analysis

The system calculates people per m² for each zone in real time. Zones are classified as Low (<1), Moderate (1–2), High (2–4), or Dangerous (>4) persons per square metre.

🗺

Heatmap Visualisation

Density levels are overlaid on a live map as colour-coded circles — green through red to black — giving operators an instant spatial view of crowd distribution.

🧭

Route Recommendation

Like a navigation app for crowds, the system suggests the least-loaded paths with directional indicators (N/S/E/W compass) so visitors can move safely and quickly.

⚠️

Stampede Prediction

ML algorithms analyse current density trends and historical patterns to forecast dangerous congestion before it occurs, triggering early warnings to staff and visitors.

🔔

Alert System

Tiered alerts (Info → Warning → Danger) are pushed to security personnel, event organisers, and visitors with actionable instructions such as route diversions or evacuations.

System Architecture

1

Data Collection Layer

CCTV cameras · GPS signals · WiFi/Bluetooth detection · Entry gate sensors

2

Data Processing Layer

Computer vision (OpenCV + YOLO) · ML density estimation (TensorFlow/PyTorch)

3

Application Layer

Mobile app (React Native/Flutter) · Web dashboard (Node.js/FastAPI) · Map tiles

4

Decision Layer

Route recommendations · Real-time alerts · Predictive congestion warnings
